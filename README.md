# Portal Intensifique Aprovação

Versão premium do portal, pronta para deploy estático na Vercel.

## Deploy

1. Suba esta pasta como projeto na Vercel.
2. Não é necessário build command.
3. Framework: Other / Static.
4. O arquivo `index.html` é a entrada.
